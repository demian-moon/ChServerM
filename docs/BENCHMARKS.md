# 벤치마크 기록

성능 주장의 근거. **수치 없는 성능 주장은 코드베이스에 넣지 않는다.**

## 규칙
- 마이크로 벤치마크는 BenchmarkDotNet (`Bench/`), 종단 부하는 NBomber
- Release 빌드, ServerGC, 디버거 미연결 상태에서만 측정
- 측정 환경(CPU, 코어 수, OS, .NET 버전)을 항상 기록한다 — 환경이 다르면 비교가 무의미하다
- 레이턴시는 평균이 아니라 **p50 / p99 / p999**로 기록한다
- 할당량(`Allocated`, Gen0/1/2 수집 횟수)을 처리량과 함께 기록한다
- `perf(...)` 커밋은 여기의 before/after 항목을 참조한다
