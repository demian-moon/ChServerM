## 블로커 / 열린 결정

- **⚠ 레거시 자격증명** — `LegacyServer/.../ServerGlobals.cs:103` 의 하드코딩된 MongoDB
  접속 문자열. 재사용 계획은 없지만(ADR-0037) **저장소에 커밋된 사실 자체**를 유출로 취급해
  폐기·교체할 것인지 **여러 세션째 확인 대기**
- **⚠ `IClusterMembership` 은 아직 가설** — 두 번째 구현(Consul·etcd·K8s) 전까지.
  실제 제공자의 알림이 `WaitForChangeAsync` 하나로 표현되는가, "일시적 이탈" 과
  "영구 제거" 의 구분이 리밸런싱에서 필요한가(ADR-0047)
- **⚠ 노드 번호 유일성은 조립 시점만 강제된다** — 서로 다른 목록을 들고 기동하면 여전히
  겹칠 수 있고, 그러면 `ObjectId` 가 조용히 충돌한다(ADR-0048, 로드맵 항목으로 추가)
- **⚠ 피어 링크 미검증 넷** — `QueueFull`(소비자를 결정적으로 멈출 방법이 없다) ·
  대여 버퍼 반납 · 재연결 경로 · 부하 아래 처리량(ADR-0050)
- **⚠ 거부 통지는 최선 노력** — 플러시 직후 끊어 TCP 는 RST 로 사유를 버릴 수 있다.
  **의도된 트레이드오프**(기다리면 그것이 공격 표면, ADR-0044)
- **Excel → CSV 변환 도구는 조건부 보류** — 레거시의 참조 0이 "수요가 없었다" 는 증거일 수
  있어 **실제 요청이 올 때** 만든다(ADR-0046)
- **GC 기본값은 잠정**(ADR-0031) · **CI 24h soak 스케줄 미정**
- **환경 상태** — SDK **10.0.201** 고정. Docker Desktop 실행 중(Redis·Garnet·PostgreSQL)
- **보류 유지** — Tsavorite(ADR-0038) / Bulkhead 강제 / `FramesSent` /
  Phase 7 누락 핸들러 검출 / 회로 상태 진단 노출
