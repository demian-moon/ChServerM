## 완료된 것

- **Part I~II 골격** — Core 무의존 추상화, 고정 헤더 프레이밍, TCP/Kestrel 전송, 직렬화 4종,
  소스 제너레이터 디스패치, 파티션 실행 모델, TLS, 미들웨어 파이프라인
- **Part III 운영 축(Phase 9~12) 완결** — 수용 제어·속도 제한·우아한 열화·헬스체크·크래시
  처리·메트릭/추적/진단·MEL 로깅. **회귀 방어 3종**(할당·비율·확장성) 모두 고의 회귀로 검증
- **성능 기준선 실측** — 169k RPS · 1만 접속 · 프레임당 0B · 코어 확장 14.79×/16코어 ·
  프레임워크 세금(raw Kestrel 대비) 저부하 −13.5% / 고동시성 **p99 −34%**
- **Phase 13 세션 축** — `ISessionStore`(바이트+CAS+TTL) · 인메모리 참조 구현 · Redis 어댑터
  (Lua CAS) · **적합성 스위트 21종을 두 구현이 함께 통과** · 세션 복구/재접속(회전 토큰) ·
  **와이어 프로토콜**(예약 ID 40007~40009 + Core 동결 코덱) · `ServerBuilder.UseSessions`
- **서킷 브레이커** — ADR-0027 보류 해제. 첫 실물은 Redis 세션 저장소
- 전 스위트 **821개** 통과, 빌드 경고 0

## 블로커 / 열린 결정

- **⚠ 레거시 자격증명** — `LegacyServer/.../ServerGlobals.cs:103` 의 하드코딩된 MongoDB
  접속 문자열. 저장소에 커밋된 이상 **유출된 것으로 취급**해야 하며, 로컬 개발 외로
  재사용한다면 폐기·교체가 필요하다. **어댑터는 PostgreSQL 로 결정**됐으므로(ADR-0037) 이 자격증명을 재사용할 계획은 없다. 다만 **저장소에 커밋된 사실 자체가 남아 있으므로** 폐기·교체 여부는 여전히 사용자 확인 대기
- **GC 기본값은 잠정** — `ServerGarbageCollection=true` + DATAS 기본을 유지했지만 루프백
  측정에서는 Workstation 이 p99 가 더 좋았다. 전용 머신 재측정 전까지 확정 아님(ADR-0031)
- **CI 스케줄 미정** — 24h soak(비율 게이트는 이미 CI 상시)
- **환경 상태** — Docker Desktop 실행 중(Redis 테스트용, 사용자 승인).
  진단 도구 3종(`dotnet-trace`/`counters`/`gcdump`) 전역 설치됨
- **보류 유지** — Bulkhead 강제(핸들러 타임아웃) / `FramesSent`(FrameWriter static 제약) /
  Phase 7 누락 핸들러 검출(메시지 레지스트리 선행) / 회로 상태 메트릭·진단 노출
