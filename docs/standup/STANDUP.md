## 다음 (우선순위 순)

1. **⚠ 파티셔닝 / 라우팅 전략**(Phase 15) — **`PartitionKey.ToIndex(노드 수)` 를 그대로
   쓰면 안 된다.** 프로세스 내 파티션은 개수가 고정이라 괜찮았지만, 클러스터는 노드 하나가
   바뀌면 **거의 모든 키가 재배치된다**. 일관 해싱 또는 랑데뷰(HRW)가 필요하고, 노드 이름을
   링에 올리는 해시는 **Core 밖**에 둔다(Core 는 서드파티 의존 0, ADR-0047)
2. **노드 간 통신**(Phase 15) — 내부 전송 경로. 기존 전송 축을 재사용할 수 있는지부터

   `CONSISTENCY.md` 4절의 방안 셋 중 하나를 고를 시점이 가까워졌다
4. **미측정 보완** — 경합 아래 확장성 · 전용 머신 GC 재측정(ADR-0031) ·
   24h soak 를 CI 에 스케줄
5. **스냅샷 전송 배선 예제** — 프레임워크가 아니라 `Samples/` 에서 보여 준다(ADR-0045)

## 블로커 / 열린 결정

- **⚠ 레거시 자격증명** — `LegacyServer/.../ServerGlobals.cs:103` 의 하드코딩된 MongoDB
  접속 문자열. 재사용 계획은 없지만(ADR-0037) **저장소에 커밋된 사실 자체**를 유출로 취급해
  폐기·교체할 것인지는 여전히 사용자 확인 대기
- **⚠ `IClusterMembership` 은 아직 가설이다** — 두 번째 구현(Consul·etcd·K8s) 전까지.
  검증되지 않은 것: 실제 제공자의 알림이 `WaitForChangeAsync` 하나로 표현되는가,
  "일시적 이탈" 과 "영구 제거" 의 구분이 리밸런싱에서 필요한가(ADR-0047)
- **⚠ 거부 통지는 최선 노력이다**(ADR-0044) — 서버가 플러시 직후 끊어 TCP 는 RST 로 사유를
  버릴 수 있다. 버전 거부 경로도 같으며 **의도된 트레이드오프**(기다리면 그것이 공격 표면)
- **Excel → CSV 변환 도구는 조건부 보류** — 레거시의 참조 0이 "수요가 없었다" 는 증거일 수
  있어 **실제 요청이 올 때** 만든다(ADR-0046). 붙일 자리는 이미 서 있다
- **GC 기본값은 잠정** — 루프백에서는 Workstation 이 p99 가 더 좋았다. 전용 머신 재측정
  전까지 확정 아님(ADR-0031)
- **CI 스케줄 미정** — 24h soak(비율 게이트는 이미 CI 상시)
- **환경 상태** — SDK **10.0.201** 고정(2026-08-10 밴드 이동). Docker Desktop 실행 중
  (Redis·Garnet·PostgreSQL 테스트용). 진단 도구 3종 전역 설치됨
- **보류 유지** — Tsavorite 어댑터(ADR-0038) / Bulkhead 강제 / `FramesSent` /
  Phase 7 누락 핸들러 검출 / 회로 상태 진단 노출
