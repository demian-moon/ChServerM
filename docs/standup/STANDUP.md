## 완료된 것

- **Part I~II 골격** — Core 무의존 추상화, 고정 헤더 프레이밍, TCP/Kestrel 전송, 직렬화 4종,
  소스 제너레이터 디스패치, 파티션 실행 모델, TLS, 미들웨어 파이프라인
- **Part III 운영 축(Phase 9~12) 완결** — 수용 제어·속도 제한·우아한 열화·헬스체크·크래시
  처리·메트릭/추적/진단·MEL 로깅. **회귀 방어 3종** 모두 고의 회귀로 검증
- **성능 기준선 실측** — 169k RPS · 1만 접속 · 코어 확장 14.79×/16코어 ·
  프레임워크 세금(raw Kestrel 대비) 고동시성 **p99 −34%**
- **Phase 13 세션 축(10/13)** — `ISessionStore` 적합성 스위트 21종을 **네 저장소가 통과**:
  인메모리 · Redis · **Garnet**(어댑터 코드 0) · **PostgreSQL**
- **Phase 14 데이터 테이블(7/8)** — 선택 축. 전수 검증 · 핫 리로드 · 강타입 접근자 제너레이터 ·
  콘텐츠 지문 게이트 · 표 스냅샷 · CSV 헤더 대조를 컴파일 타임으로
- **Phase 15 클러스터(6/15)** — `IClusterMembership`(정적 목록) · **랑데뷰(HRW) 라우팅**
  (노드당 1.1ns) · **로컬 단락**(`ClusterRoute`) · **피어 링크**(`ChServerM.Cluster.Hosting`) ·
  ⭐ **피어 링크 미검증 넷 해소 — 셋이 결함이었다**(ADR-0051)
- 전 스위트 **1114개** 통과, **전체 재빌드** 경고 0

## 다음 (우선순위 순)

   닫을 수 있다
2. **리밸런싱**(Phase 15) — 노드 추가/제거 시 상태 이동. `GetOwners` 의 상위 k 가 그 재료다.
   ⚠ **대량 상태 이동은 정확히 깊은 큐 + 큰 페이로드 경로**이므로 1번이 그 설계의 입력이다
3. **리더 선출 / 스플릿 브레인**(Phase 15) — 정적 목록에서 무엇이 제공자의 몫인지부터 가른다
   (**장애 판정을 하지 않는다**, ADR-0047)
4. **무중단 배포 — 커넥션 드레인**(Phase 15)
5. **Redis Cluster 미지원 해소**(Phase 13 잔여) — 클러스터 축이 생겼으므로
   `CONSISTENCY.md` 4절의 방안 셋 중 하나를 고를 시점이다

## 블로커 / 열린 결정

- **⚠ 레거시 자격증명** — `LegacyServer/.../ServerGlobals.cs:103` 의 하드코딩된 MongoDB
  접속 문자열. 재사용 계획은 없지만(ADR-0037) **저장소에 커밋된 사실 자체**를 유출로 취급해
  폐기·교체할 것인지 **여러 세션째 확인 대기**
- **⚠ 피어 링크 버퍼 풀의 기본값이 함정이다**(ADR-0051 열린 결정) — 4-인자 생성자가
  `ArrayPool<byte>.Shared` 를 쓰므로 큐를 깊게 잡으면 **경고도 오류도 없이 33% 손해**를 본다.
  선결: 전용 풀 보유 메모리 상한(기본 `MaxPayloadLength` 1 MiB × 버킷 합산이 GB 가 될 수 있다)
- **⚠ "프레임당 힙 할당 0" 은 큐 깊이에 조건부다**(2026-08-10 발견) — 미처리 대여물이
  **설정 용량**(큐 깊이·최대 커넥션 수)에 비례하는 경로가 함정이다.
  `PooledBufferWriter`(⚠ **권장 사용법이 곧 함정의 모양** — 커넥션당 하나를 커넥션 수명 내내
  보유) · `FragmentAssembler`(조건부) **미측정**
- **⚠ `IClusterMembership` 은 아직 가설** — 두 번째 구현(Consul·etcd·K8s) 전까지.
  "일시적 이탈" 과 "영구 제거" 의 구분이 리밸런싱에서 필요한가(ADR-0047)
- **⚠ 노드 번호 유일성은 조립 시점만 강제된다** — 서로 다른 목록을 들고 기동하면 겹칠 수 있고,
  그러면 `ObjectId` 가 조용히 충돌한다(ADR-0048). 멤버십 제공자가 배정해야 풀리므로
  두 번째 구현과 함께 간다
- **⚠ 거부 통지는 최선 노력** — 플러시 직후 끊어 TCP 는 RST 로 사유를 버릴 수 있다.
  **의도된 트레이드오프**(ADR-0044)
- **Excel → CSV 변환 도구는 조건부 보류**(ADR-0046) · **GC 기본값 잠정**(ADR-0031) ·
  **CI 24h soak 스케줄 미정**
- **환경 상태** — SDK **10.0.201** 고정. Docker Desktop 실행 중(Redis·Garnet·PostgreSQL)
- **보류 유지** — Tsavorite(ADR-0038) / Bulkhead 강제 / `FramesSent` /
  Phase 7 누락 핸들러 검출 / 회로 상태 진단 노출
