### Stage 2 — 네트워크 축 인터페이스 (`a21cd44`)

`Connections/` `Transports/` `Framing/` `Serialization/` `Dispatch/` `Execution/`.

### Stage 3 — `ChServerM.Framing` (`eb3b744`)

### Stage 4 — 인메모리 전송 + 디스패처 (`04310a0`)

`ChServerM.Hosting`(Core만 참조) + `ChServerM.Transport.InMemory`.

- `FramedConnectionHandler` — **`AdvanceTo`는 그 읽기에서 나온 모든 프레임의 디스패치가 끝난 뒤에만**
  부른다. 프레임 단위로 부르면 핸들러가 해제된 메모리를 본다
- **미들웨어가 라우팅보다 앞에 있다.** 반대면 모르는 ID를 보내는 것만으로 인증을 우회할 수 있다

### Stage 5 — TCP 전송 (`a4a1221`)

raw `Socket` + Pipelines. `TcpClient`/`NetworkStream`을 쓰지 않는다.

- 소켓 작업에 `CancellationToken`을 넘기지 않는다. 중단은 `Socket.Dispose()` — Kestrel과 같은 방식
- **0바이트 수신으로 대기**(`WaitForDataBeforeAllocating`). 1만 유휴 접속 × 4KB = 40MB 절감.
  레거시는 커넥션당 64KB를 상수로 붙들었다(= 640MB)
- 부분 전송 처리. `SendAsync`가 전부 보낸다는 보장이 없고, 놓치면 조용히 잘린 프레임이 나간다
- 수락 루프가 일시적 오류와 치명적 오류를 구분한다. 구분하지 않으면 조용히 수용을 멈추거나 CPU를 태운다
- `IOControlCode.KeepAliveValues`를 쓰지 않는다 — Windows 전용, 레거시의 크로스 플랫폼 차단 요인

## 잡은 결함 3건

### 1. `SocketConnection.Abort`가 송신 펌프를 깨우지 않음

소켓만 닫아서는 부족하다. 송신 펌프는 소켓이 아니라 **파이프**에서 대기하고 있어서,
`Abort`된 커넥션의 `DisposeAsync`가 영구 교착했다. `CancelPendingPipeReads()` 추가 +
`WaitForPumpsAsync`에 제한 시간.

### 2. 최대 프레임 > 전송 버퍼 = 영구 교착 (ADR-0007)

축 두 개의 성질이 충돌한다. 디코더는 완전한 프레임 전에 아무것도 소비할 수 없고(경계를 잃으므로),
전송 버퍼는 미소비 바이트가 임계값에 닿으면 쓰기를 멈춘다.

| 임계값 | 페이로드 | 결과 |
|---|---|---|
| 64 KiB | 200 KB | **교착** |
| 64 KiB | 40 KB | 정상 |
| 512 KiB | 200 KB | 정상 |

**TCP가 통과한 건 커널 버퍼가 흡수한 우연이었다.** 그리고 **기본값 조합(프레이밍 1MiB /
전송 64KiB)부터 이미 깨져 있었다.**

→ Core에 `ITransportBufferLimits`, 빌더의 `CompositionGuard`가 `Build()`에서 검사해
**조용한 교착을 시작 시점 예외로** 전환. 기본값은 일부러 맞추지 않았다 — 전송을 1MiB로 올리면
1만 접속에 20GB이고, 프레이밍을 64KiB로 낮추면 정당한 워크로드를 막는다.

### 3. 테스트가 대기 중인 `ManualResetEventSlim`을 `Dispose`

대기자가 있는 상태의 `Dispose`는 동작이 정의되지 않는다. 테스트 코드 쪽 결함이었다.

두 건(1·2)은 **`dotnet test`가 "테스트 호스트 프로세스 작동이 중단됨"으로 죽어서** 발견됐다.
72개 테스트가 전부 통과한 뒤 종료 시점에 걸렸고, 클래스 → 메서드 순으로 좁혀
독립 재현 프로그램을 만들어야 원인이 드러났다.

다른 작업 환경에서 같은 조건으로 이어가기 위해 이전 결정(로컬 참조 전용)을 뒤집었다.
`LegacyServer/` 133 파일 + `LagacyClient/` 16 파일, 빌드 산출물 0개.
**승계 방침은 그대로** — 솔루션에 없으므로 빌드·테스트·CI 가 컴파일하지 않는다(감사도 11개 프로젝트만).

재현성에서 구멍 하나를 발견했다. MCP 차단 설정이 `settings.local.json` 에만 있었고
그 파일은 사용자 전역 gitignore 에 걸려 공유되지 않는다 — 다른 환경에서는 MCP 25개가
그대로 살아났을 것이다. `.claude/settings.json` 으로 옮겼다.
