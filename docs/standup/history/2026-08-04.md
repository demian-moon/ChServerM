# 2026-08-04

**정밀 감사의 날.** 사용자 요청으로 전체 산출물(코드·문서·계획)을 5축(아키텍처 / 동시성 /
전송·프레이밍 / 문서·계획 / 테스트·검증)으로 병렬 감사했고, 그 결과가 하루 전체의 작업을
결정했다. **핵심 발견: ADR-0005 의 "파티션 고정"이 검증 장치 세 겹(테스트·벤치마크·통합
경로)을 모두 통과했는데도 실전 경로에서 깨져 있었다.**

## 한 일

### 1. 정밀 감사 (5축 병렬)

주요 발견 (심각도순):

- **🔴 파티션 고정 반증** — ① Pipe 의 `ReaderScheduler` 기본값(스레드풀) +
  `ConfigureAwait(false)` 로 첫 미완료 await 이후 핸들러가 파티션 스레드를 이탈,
  ② 고정 검증 테스트는 실전과 정반대 await 조합(`Task.Yield`+`ConfigureAwait(true)`)만 검증,
  ③ 통합 하네스가 `ServerBuilder` 를 우회해 `PartitionedConnectionHandler` 실행 테스트 0개,
  ④ 확장성 곡선은 청크 단위라 어떤 모델이든 좋게 나오는 측정
- **H1** TCP 등록 경합(핸들러 기동이 등록보다 먼저 → 죽은 항목 영구 잔류) /
  **H2** InMemory `Abort` 의 파이프 소유권 위반(TCP 와 동작 비대칭 — ADR-0004 자기 위반) /
  **H3** InMemory 종료 드레인 무한 대기(서버 종료가 커넥션 하나에 볼모)
- **H4** Core 프레이밍 계약이 고정 16B 헤더에 결박(varint·stateless-web 차단) — 미수정, ROADMAP 등재
- **문서**: ROADMAP 중복 항목(분모 오염), ADR-0005 측정의 근거 커밋 오류(재현 체인 단절),
  Phase 5 `[x]` 2건 DoD-3 미충족, "두 번째 구현 전 가설" 미자인 축 다수
- **계획**: 프로토콜 버전 협상 부재(무중단 배포와 구조 충돌), Phase 13~22 게이트 전무

### 2. 반증 고정 → ADR-0008 액터형 파티션 (`a159386`, `8c6b125`)

프로덕션 조립 경로 그대로의 반증 테스트로 결함을 실측 고정(같은 파티션 두 커넥션 핸들러의
**병렬 실행** 관측). 사용자 선택으로 **액터형** 채택:

- 배타성의 정의 변경: "같은 스레드" → **"완료까지 다음 작업을 시작하지 않음"** —
  `ConfigureAwait(false)` 와 무관하게 성립
- Core `IPartitionExclusiveWork` + `TryEnqueueExclusive`, 파티션 소비 루프가 완료까지 블로킹,
  Hosting `PartitionDispatchGate`(커넥션당 1개, `IValueTaskSource`, 동기 완료 시 무할당),
  `PartitionedConnectionHandler` 삭제
- 반증 테스트를 **계약 테스트 3종으로 반전**(동기 구간 파티션 스레드 고정 / 동기 핸들러
  비중첩 / **await 를 걸치는 비동기 핸들러의 배타성**)

### 3. 메시지 단위 벤치마크 — 나쁜 결과 포함 그대로 기록

ENV-B(7945HX, 물리 16/논리 32) 신규 등록. `PartitionExclusiveBenchmarks`:

- 프레임당 배타 왕복 **+0.70µs** (P=1, 1µs 작업 기준 1.94×) — 배타성의 정직한 가격표
- ⚠ 핑퐁 구조(파티션당 커넥션 1)에서 **P=8부터 역확장** — 최악 사례, 바쁨 구성은 미측정
- ⚠ **프레임당 할당 ~170-184 B 실측** — "할당 0" 이 이 경로에서 깨짐. 원인 특정
  (완료 신호 스레드풀 큐 항목 + `WaitForWork` 의 `AsTask()` — 후자는 구 설계에도 있었다)

### 4. 감사 결함 수정 2회분 (`7be5f46`, `396f6d5`)

- **H1~H3** + 회귀 테스트 3건(`ConnectionLifecycleRegressionTests`)
- 잔여 일괄: 클라이언트 전송 추적 누수(ConnectionClosed 등록 제거), `SocketConnection`
  후발 경로 `SignalClosed` 누락, TCP 옵션 스냅샷(ADR-0007 사후 무효화 봉쇄), InMemory

  상한 엄격화(증가-검사-롤백), 파티션 공유 데드라인 종료, 박스 반납 참조 절단,

### ADR-0008 후속 성능 작업 (`bc8ec95`, `4a13898`)

프레임당 할당 184B → **~0.01B** (Gen0 33k회 → 0). 교정 3건:
게이트 자신을 IThreadPoolWorkItem 으로(완료 신호 큐 항목 할당 제거) /
소비 루프 대기를 재사용 이벤트+캐시 콜백으로 / WaitToReadAsync 토큰 미전달
(취소 가능 토큰이 채널 싱글턴 waiter 재사용을 막고 있었다 — 측정 중 추가 발견).
바쁜 소비자 구성 신설: 실부하 근사 +0.26µs/프레임, P=4까지 3.16× — 핑퐁
역확장이 깨우기 비용 지배임을 확인. 트레이드오프(핑퐁 P≤2 벽시계 ~10%↑)도 기록.
부수 사고: PS5.1 인코딩 함정으로 ROADMAP 손상 커밋 1개 발생 → 즉시 reset 후 재적용.
